# R6 - Reliability contract
## R6.3
- Goal: pin engine/hash versions in encrypted immutable snapshots; replay absent metadata permanently as legacy v1.
- Files: src/core/engine, captured-evidence verifier, server calculation repository; additive compatibility fixtures/tests only.
- Rule: v1 arithmetic and canonical hash payload stay unchanged; unknown/partial version pairs fail closed; future versions need separate implementations/goldens.
- Done when: pre-change golden hashes reproduce for legacy/explicit v1, new saves pin/replay the selected version, malformed versions never write or replay.
- Checks: fail-first, focused/full unit, lint/typecheck, independent H review and disposable CI; no migration/UI/provider calls.
- Rollback: revert code; existing JSON metadata remains readable by this version, never rewrite calculations or old hashes.
